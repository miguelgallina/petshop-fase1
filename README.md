# PataFeliz PetShop — Sistema Web (Fase 1)

## Sobre o Projeto

Este projeto é um sistema web de comércio de produtos e serviços para um petshop chamado **PataFeliz PetShop**.
Foi desenvolvido como Projeto da Disciplina de Desenvolvimento Web — Fase 1.

O sistema foi construído utilizando apenas **HTML puro**, sem uso de CSS customizado, Bootstrap ou JavaScript,
conforme os requisitos da Fase 1 da disciplina.

## Páginas e Funcionalidades

### 1. Página Inicial — `index.html`
- Apresentação da PataFeliz PetShop
- Tabela com as 3 categorias de produtos e links para cada categoria
- Resumo dos serviços disponíveis
- Horário de funcionamento da loja
- Cabeçalho com navegação completa
- Rodapé com informações legais e de contato

### 2. Acessórios — `acessorios.html`
Exibe **2 produtos da categoria Acessórios**:
- **Coleira Ajustável com Plaquinha Personalizada** — R$ 35,90
  - Foto do produto, descrição completa e características
- **Caminha Redonda Pelúcia Super Soft** — R$ 89,90
  - Foto do produto, descrição completa e características

### 3. Rações — `racoes.html`
Exibe **2 produtos da categoria Rações Não Perecíveis**:
- **Ração Seca Premium para Cães Adultos (15 kg)** — R$ 189,90
  - Foto do produto, descrição completa e tabela nutricional
- **Ração Seca Premium para Gatos Adultos (10 kg)** — R$ 149,90
  - Foto do produto, descrição completa e tabela nutricional

### 4. Higiene e Limpeza — `higiene.html`
Exibe **2 produtos da categoria Higiene e Limpeza**:
- **Tapete Higiênico para Cães (pacote c/ 30 unidades)** — R$ 49,90
  - Foto do produto, descrição completa e características
- **Fralda Higiênica Descartável para Pets (pacote c/ 12 unidades)** — R$ 39,90
  - Foto do produto, descrição completa e características

### 5. Serviços — `servicos.html`
Exibe os **2 serviços de Banho e Tosa**:
- **Banho e Tosa (Sem Tele-Busca)**
  - Descrição completa do serviço
  - Tabela de valores por porte (Pequeno, Médio, Grande)
  - Modalidades: Banho simples, Banho + Tosa Higiênica, Banho + Tosa Completa
- **Banho e Tosa com Tele-Busca**
  - Descrição completa, incluindo detalhes sobre o transporte
  - Tabela de valores por porte com taxa de tele-busca incluída
- Instruções de agendamento e formas de pagamento aceitas

## Estrutura de Cada Página

Todas as páginas seguem a mesma estrutura:

1. **Cabeçalho (`<header>`)**: Nome do petshop, slogan, telefone, endereço e menu de navegação
2. **Corpo (`<main>`)**: Conteúdo específico de cada página (produtos ou serviços)
3. **Rodapé (`<footer>`)**: Links de navegação, contato, endereço, redes sociais e informações legais (copyright, CNPJ)

---

## Tecnologias Utilizadas

- **HTML5** — Linguagem de marcação para estruturação das páginas
- **Sem CSS** — Nenhuma folha de estilo customizada (conforme requisito da Fase 1)
- **Sem Bootstrap** — Nenhum framework CSS utilizado (conforme requisito da Fase 1)
- **Sem JavaScript** — Nenhum script de comportamento (conforme requisito da Fase 1)
